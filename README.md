# POS Abadi Jaya Copier 🚀

Sistem Kasir (Point of Sale) & ERP khusus untuk usaha Fotocopy, Percetakan, dan Alat Tulis Kantor (ATK) yang dirancang untuk efisiensi maksimal dan manajemen terpadu.

## 🌟 Fitur Unggulan Terbaru (2024 Update)

Aplikasi ini telah berkembang menjadi sistem manajemen bisnis yang lengkap dengan fitur-fitur baru berikut:

### 1. Modul Barcode & Label Harga Otomatis
- **Cetak Massal**: Memungkinkan cetak stiker harga/barcode dalam jumlah banyak sekaligus.
- **Presisi Label**: Desain khusus untuk ukuran label thermal 50mm x 30mm yang presisi.
- **Toggle Garis Potong**: Fitur garis pembantu untuk pemotongan manual pada kertas stiker A4.
- **Barcode Sync**: Menggunakan font `Libre Barcode 39` untuk pemindaian yang akurat.

### 2. Manajemen Keuangan & Jurnal Kas
- **Laporan Jurnal Umum**: Rekapitulasi otomatis seluruh transaksi kas masuk dan keluar.
- **Export PDF Professional**: Cetak laporan jurnal dengan kop surat toko yang elegan dan tanda tangan admin/pemilik.
- **Filter Tab-Specific**: Kemudahan dalam melihat dan mencetak histori kas berdasarkan kategori (Kas Masuk, Kas Keluar, Jurnal Umum).

### 3. Sinkronisasi Branding Global (Branding Sync)
- **Kop Toko Otomatis**: Nama toko, alamat lengkap, dan nomor WhatsApp otomatis muncul di seluruh laporan cetak (Jurnal, Invoice, Barcode).
- **Identity Manager**: Kelola seluruh identitas bisnis dari satu pintu melalui menu Pengaturan.

### 4. Landing Page Premium & WhatsApp Integration
- **Website Publik**: Halaman depan modern yang responsif untuk branding online.
- **Direct Order**: Pelanggan bisa memesan produk atau request service langsung terhubung ke WhatsApp.

### 5. Otomasi Pembayaran QRIS (Midtrans)
- **Live QRIS Dashboard**: Monitoring pembayaran digital secara real-time.
- **Webhook Settlement**: Status piutang otomatis berubah menjadi "Lunas" saat pelanggan berhasil membayar via QRIS.

## 🛠️ Cara Instalasi & Menjalankan

### Frontend (Client)
1. Masuk ke folder `client`
2. Jalankan `npm install`
3. Jalankan `npm run dev`

### Backend (Server)
1. Masuk ke folder `server`
2. Jalankan `npm install`
3. Jalankan `npm start` (atau gunakan `nodemon`)
